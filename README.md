# Calculadora de Descuentos
Una calculadora sencilla en **HTML y JavaScript** que permite calcular el precio final de un producto aplicando un porcentaje de descuento.
# Link
https://martinaxx.github.io/calculadora_descuento/

## Cómo usar:
1. Ingresar el precio original del producto.
2. Ingresar el porcentaje de descuento.
3. Presionar el botón **Calcular**.
4. El resultado mostrará el precio final.

## Adaptación a móviles
Inicialmente, en el celular el texto se veía muy pequeño y era necesario hacer zoom. Lo solucioné configurando correctamente el `viewport`, logrando que la calculadora sea totalmente legible y adaptable a pantallas pequeñas.

## Características
- Validación para evitar precios negativos.
- El calcula se realiza la presionar el botón **Calcular**.
- Diseño adaptable a dispositivos móviles.

## Tecnologías y aprendizajes
- HTML y JavaScript para la lógica del cálculo.
- Uso de variables y funciones para procesar datos.
- Configuración del viewport para mejorar la experiencia en dispositivos móviles.
