# Calculadora de Descuentos
Una calculadora sencilla en HTML que permite calcular el precio final de un producto aplicando el descuento.

## Como usar:
1. Ingresar el precio original del producto.
2. Ingresar el porcentaje de descuento.
3. Apretar el botón de calcular.

### Características
- Tiene validacion para precios negativos.
- El calcula es automático.

### Tecnologias y que aprendi
utiliza HTML, aprendí como hacer funciones, como guardar datos en una variable, hacer funciones y además de la visibilidad adaptable a teléfonos móviles.
